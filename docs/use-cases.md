# Use Cases

Use cases group multiple TTPs into real-world program scenarios. They are intended for planning and discussion, not as implementation specifications.

## Departing Employee Risk

Relevant TTPs:

- `IT1007` Pending Termination/Resignation
- `IT1024` Upload to 3rd Party File Share
- `IT1025` External Email with Attachments
- `IT1026` Upload to Removable Storage Device
- `IT1040` Use of File Share Site with External User
- `IT1042` Multiple Employees Leaving to Same Company
- `IT1053` Personal Cloud Sync Client

Planning focus:

- Offboarding process ownership
- Access timing and revocation standards
- Sensitive data handling expectations
- HR, legal, privacy, and security review path

## Intellectual Property Protection

Relevant TTPs:

- `IT1018` Downloads from Application
- `IT1019` Downloads from Internal File Share
- `IT1023` Copying System Backups
- `IT1039` Exposure of Sensitive/Confidential Information in Public Repositories
- `IT1052` Sensitive Data in External AI Tools
- `IT1054` Copying Sensitive Data to Clipboard

Planning focus:

- Crown-jewel data definition
- R&D and engineering access governance
- Approved collaboration and AI tooling
- External sharing and publication review

## Privileged Misuse

Relevant TTPs:

- `IT1016` Modify/Delete Logs
- `IT1017` Use of Offensive/Malicious Tools
- `IT1031` Changing Service Account Password
- `IT1032` Malicious Changes to Application/System
- `IT1043` Role-Based Access
- `IT1044` Logging and Monitoring

Planning focus:

- Privileged access review
- Separation of duties
- Emergency access process
- Logging and administrative accountability

## Fraud, Misuse, and Business Impact

Relevant TTPs:

- `IT1029` Bulk Delete Files
- `IT1034` Misappropriations of Funds
- `IT1035` Anomalous Timekeeping Activity
- `IT1036` Misappropriations of Assets
- `IT1038` Insider Trading Violations
- `IT1048` Unauthorized 3rd Party Outsourcing

Planning focus:

- Financial approval processes
- Asset and timekeeping governance
- Business-unit escalation paths
- Legal and compliance coordination

## Modern SaaS and AI Risk

Relevant TTPs:

- `IT1051` Unauthorized OAuth Application Consent
- `IT1052` Sensitive Data in External AI Tools
- `IT1053` Personal Cloud Sync Client
- `IT1054` Copying Sensitive Data to Clipboard

Planning focus:

- Approved AI and SaaS usage policy
- Third-party app review
- Personal account and unmanaged storage expectations
- Employee guidance on sensitive data handling
